# Trzy-dni-zwiedzania-Tsavo-East-Tsavo-West
This is an interactive 3D map of a 3-day road safari from Diani Beach on Kenya's south coast. The trip covers both halves of the Tsavo ecosystem, which together form one of the largest protected wildlife areas in Africa. Visitors see the open red-earth plains of Tsavo East and the volcanic hills of Tsavo West.
